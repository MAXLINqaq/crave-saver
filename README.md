# crave-saver 忍住记

嘴馋想点外卖时，把菜品加入购物车、走到支付确认页——**然后不付款**，打开本 App 记下这笔"忍住没花的钱"，看着 savings 越攒越多。

## 产品概念

把外卖 App 当成记账的触发器：

1. 在美团/京东/淘宝等 App 里选好菜品，进入支付确认页（不付款）
2. 切到本 App，记录店名、菜品、金额
3. 这笔钱计为一笔"忍住没花"的储蓄，累计展示
4. 用攒钱总额、连续忍住天数等正反馈对抗冲动消费

## 可行性结论

| 方案 | 可行性 | 说明 |
| --- | --- | --- |
| 自动拦截支付 | ❌ 不可行 | 外卖/电商 App 无开放 API，无法在支付前拦截订单（Root 除外，不考虑） |
| 手动快速记账 | ✅ 可行 | MVP 核心，开发量小 |
| 截图 + OCR 识别 | ✅ 可行 | 支付页截图导入，ML Kit 本地 OCR 识别店名/金额，自动填单 |
| Android 无障碍监听 | ⚠️ 勉强可行 | 脆弱（目标 App 改版即失效）、上架审核风险，不纳入首发 |

## 首发范围（Android MVP）

- 手动记账：店名、菜品（多条）、金额、备注、时间
- 截图 OCR：从相册/分享接收支付页截图，ML Kit 识别金额与店名，用户确认后入账
- 攒钱多维度展示：总额、本月、趋势图、连续忍住天数
- 纯本地存储（Room），无账号体系

## 技术栈

- Kotlin + Jetpack Compose
- Room（本地数据库）
- ML Kit Text Recognition（端上 OCR，免费）
- 最低支持 Android 8.0（API 26）
